# 20.2. 보이지 않는 지식망의 시각화: OntoGraf와 VOWL을 활용한 네트워크 맵핑

## 1. 도입: 장님 코끼리 만지기와 텍스트의 한계

**"시맨틱웹과한국학자료"**나 **"고문헌자료정보화연구"** 수업에서 대학원생들이 가장 답답함을 호소하는 순간이 있습니다. 여러분은 16장부터 19장까지 피땀 흘려 클래스를 설계하고, 화살표를 만들고, 인스턴스를 입력했습니다. 기계의 뇌를 깨워 추론까지 마쳤습니다. 

그런데 지도 교수님이나 연구 재단의 심사위원들이 묻습니다. 
**"그래서, 그 한국근대인물LOD의 종묘배향공신 관계망이 도대체 어떻게 생겼다는 겁니까? 전체 그림을 좀 보여주십시오."**

여러분이 보여줄 수 있는 것은 Protégé 좌측에 있는 윈도우 탐색기 모양의 딱딱한 텍스트 트리(Tree) 구조나, 우측 패널에 빼곡하게 적힌 거북이 문법(Turtle) 텍스트뿐입니다. 인문학자들에게 코드와 폴더 구조만 들이밀며 **"이 안에 위대한 지식망이 들어있습니다"**라고 우기는 것은, 장님에게 코끼리 다리 하나만 만지게 하고 전체 코끼리의 웅장함을 상상하라는 것과 같은 폭력입니다.

우리가 설계한 거대한 지식의 우주를 직관적이고 아름다운 노드(Node)와 링크(Link)의 네트워크 지도로 시각화하여, 누구나 한눈에 역사적 맥락을 파악할 수 있도록 만들어주는 마법의 캔버스가 필요합니다.

## 2. 해결책 제시: 분석용 "OntoGraf"와 발표용 "WebVOWL"



시맨틱 웹 진영에는 텍스트로 짜인 온톨로지 코드를 2차원 또는 3차원 네트워크 그래프로 변환해 주는 두 가지 위대한 시각화 도구가 존재합니다. 목적에 따라 돋보기와 드론을 번갈아 사용해야 합니다.

| 시각화 도구 | 사용 목적과 인문학적 비유 | 장점과 단점 |
| :--- | :--- | :--- |
| **"OntoGraf"** (Protégé 내장 탭) | **[분석용 돋보기]** 내가 만든 데이터가 제대로 엮였는지 검수하는 작업실 | Protégé 안에서 인스턴스 하나를 클릭해 가지를 뻗어 나가며 연결 상태를 확인하기 좋음. 전체를 한 번에 보기는 어려움. |
| **"WebVOWL"** (웹 기반 서비스) | **[발표용 드론]** 연구 성과를 대중이나 심사위원에게 우아하게 과시하는 전시장 | 클래스와 속성의 뼈대(Schema) 전체를 다채로운 색상의 원형 그래프로 아름답게 렌더링함. 인스턴스(개별 데이터) 확인에는 부적합함. |

아키텍트는 데이터 입력 중간중간 **"OntoGraf"**로 오류를 점검하고, 프로젝트가 끝난 뒤에는 **"WebVOWL"**로 뼈대를 추출하여 논문이나 발표 자료에 삽입하는 투트랙 전략을 구사해야 합니다.

## 3. 실전 적용: 종묘배향공신 네트워크의 시각적 추출

먼저 Protégé 내부에서 특정 인물(개체)의 연결망을 시각적으로 추적하는 **"OntoGraf"**의 구동법을 실습해 보겠습니다.

**[작업 1: OntoGraf 탭 활성화 및 구동]**
1. Protégé 상단 메뉴 바에서 **"Window ➔ Tabs ➔ OntoGraf"**를 클릭하여 숨겨진 시각화 탭을 꺼냅니다.
2. 캔버스 좌측의 클래스 목록에서 **"종묘배향공신"**을 찾아 클릭합니다.
3. 캔버스 중앙에 파란색 노드(종묘배향공신)가 나타납니다. 이 노드 우측에 달린 작은 플러스(+) 버튼을 마우스로 더블 클릭해 보십시오.
4. 노드가 펑 하고 터지면서, 그 아래에 소속된 **"민영환"**, **"조병세"** 등의 개체들이 화려하게 뻗어 나옵니다.
5. 다시 **"민영환"** 노드를 더블 클릭하면, 그가 역임한 **"병조판서"** 노드와 순국 연도 데이터가 거미줄처럼 펼쳐집니다.

이제 이 뼈대 구조 전체를 아름다운 색상으로 렌더링하여 발표 자료로 만들기 위해 **"WebVOWL"**을 사용해 보겠습니다.



**[작업 2: WebVOWL을 활용한 전체 뼈대 렌더링]**
1. Protégé에서 완성된 온톨로지를 **"File ➔ Save"** 하여 `.owl` 파일로 내보냅니다.
2. 웹 브라우저를 열고 `http://www.visualdataweb.de/webvowl/` (WebVOWL 공식 사이트)에 접속합니다.
3. 화면 하단의 **"Ontology ➔ Upload Ontology"** 버튼을 눌러 방금 저장한 `.owl` 파일을 업로드합니다.
4. 웹 브라우저 전체가 화려한 우주 공간으로 변하며, 노란색(인물), 파란색(관직) 원형 노드들이 둥둥 떠다니고, 그 사이를 화살표(hasOffice)가 이어주는 환상적인 프레젠테이션 화면이 나타납니다. 화면을 캡처하여 논문에 그대로 삽입하십시오.

## 4. 실무 트러블슈팅 (Street-smart Tips)

**시맨틱 아키텍트의 파멸: OntoGraf에서 "전체 펼치기(Expand All)"를 누르는 만용**

Protégé의 OntoGraf를 처음 접한 연구원들이 마우스 클릭 한 번으로 컴퓨터를 물리적으로 다운(Freeze)시키는 무시무시한 조작 실수가 있습니다. 바로 화면 전체에 지식망을 한 번에 다 띄워보겠다며 캔버스 상단의 **"Expand All(모두 펼치기)"** 버튼이나 개별 노드의 **"Expand All"** 기능을 겁 없이 눌러버리는 행위입니다.

**"교수님! 종묘배향공신 수십 명의 네트워크가 어떻게 얽혀있는지 한눈에 보려고 `모두 펼치기`를 눌렀는데, 화면에 수만 개의 노드가 폭발하듯 쏟아지더니 Protégé가 하얗게 질리며 응답 없음으로 멈춰버렸습니다!"**

지식 그래프는 여러분이 생각하는 것보다 훨씬 조밀하고 무한하게 얽혀있습니다. 민영환을 펼치면 그의 관직, 출신지, 동료가 나오고, 그 동료를 펼치면 다시 그들의 관직과 출신지가 쏟아져 나오는 기하급수적인 연쇄 폭발(Combinatorial Explosion)이 일어납니다. 수만 개의 점과 선을 좁은 화면에 한 번에 렌더링하려 들면 그래픽 카드의 메모리가 견디지 못하고 터져버립니다.

**[승리하는 아키텍트의 시각화 철칙]**
1. OntoGraf는 반드시 **"부분 탐색용"**으로만 사용하십시오. 노드를 하나씩 더블 클릭하여 개별 인물(예: 민영환)을 중심으로 반경 1~2단계의 관계망만 시각적으로 점검하는 것이 올바른 사용법입니다.
2. 거대한 뼈대(Schema) 전체의 웅장함을 보고 싶다면, 무거운 OntoGraf 대신 웹 브라우저의 가벼운 렌더링 엔진을 사용하는 **"WebVOWL"**에 파일을 업로드하여 감상하십시오. 시각화 도구는 데이터를 다루는 메스가 아니라, 완성된 요리를 담아내는 접시일 뿐임을 명심해야 합니다.

## 5. 요약 및 다음 단계

* 텍스트와 트리 구조에 갇힌 온톨로지를 시각적인 네트워크 그래프로 변환하여 직관성을 확보하기 위해 **"OntoGraf"**와 **"WebVOWL"**이라는 도구를 활용해야 합니다.
* **"OntoGraf"**는 Protégé 내부에서 특정 인스턴스 중심의 데이터 연결 상태를 돋보기처럼 점검할 때 유용하며, **"WebVOWL"**은 전체 클래스의 뼈대(Schema)를 아름답게 렌더링하여 프레젠테이션이나 논문에 활용할 때 강력합니다.
* 시각화 도구에서 수만 건의 데이터 노드를 한 번에 펼치려(Expand All) 시도하면 시스템이 멈추는 대참사가 발생하므로, 반드시 점진적인 확장 탐색을 수행해야 합니다.

지금까지 우리는 Protégé 캔버스 위에서 마우스를 클릭하며 인물 데이터 하나하나를 장인처럼 수작업으로 깎아냈습니다. 뼈대를 세우고 소수의 샘플 데이터를 테스트하는 데에는 이 방식이 완벽합니다.

하지만 현실의 디지털 인문학 프로젝트는 가혹합니다. 국사편찬위원회나 한국학중앙연구원이 보유한 문과 급제자 명단인 **"문과방목(文科榜目)"**에는 수만 명의 데이터가 엑셀 파일에 빼곡히 들어차 있습니다. 이 수만 명의 데이터를 언제까지 마우스로 클릭하며 한 명씩 인스턴스로 만들고 있을 수는 없습니다. 

엑셀이라는 거대한 데이터 사일로(Silo)에 갇힌 수만 명의 급제자들을 구출하여, 단 한 번의 매핑(Mapping)으로 지식 그래프 무대 위에 폭포수처럼 쏟아내는 강력한 자동화 파이프라인이 절실합니다.

다음 장인 **"20.3. 엑셀 사일로의 탈출: Cellfie 플러그인을 활용한 대량의 방목(榜目) 데이터 자동 변환(Import)"**으로 진입하여, 수작업의 고통을 완전히 끝내고 엑셀 표의 규칙을 시맨틱 코드로 일괄 변환해 내는 Protégé 최고의 실무 무기, **"Cellfie(셀피)"** 플러그인의 문법을 완벽하게 마스터해 보겠습니다!
