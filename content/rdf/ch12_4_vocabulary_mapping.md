# 12.4. 글로벌 어휘 매핑: exactMatch, closeMatch를 활용한 외부 권위 데이터 연결

## 1. 도입: 우물 안 개구리를 벗어나는 시맨틱 외교

12.3장까지의 뼈를 깎는 노력으로, 우리 연구실 서버에는 '조선시대 정치 세력'이나 '한국의 전통 건축'을 완벽하게 묘사하는 정교한 시소러스(ConceptScheme)가 완성되었습니다. 동인, 서인, 남인, 북인이 얽히고, 서원(書院)과 향교(鄕校)가 분류된 세계 최고 수준의 한국학 단어장입니다.

하지만 여기서 만족한다면 우리는 그저 **'정교한 우물 안 개구리'**에 불과합니다. 
미국의 하버드 옌칭 도서관 사서가 영어로 한국의 '서원'에 관한 자료를 검색하려고 할 때, 그들의 시스템은 우리 서버의 `국학:concept/서원`이라는 로컬 주소를 알 턱이 없습니다. 우리의 귀중한 한국학 데이터가 전 세계 학자들에게 노출(Discoverable)되려면, 미국의 의회도서관 주제명 표목(LCSH)이나 전 세계 공용 지식망인 위키데이터(Wikidata)의 어휘들과 **'시맨틱 외교(Semantic Diplomacy)'**를 맺어야 합니다.

서로 다른 사전(Scheme)에 속한 두 개의 이질적인 개념을 연결하여 지식의 다리를 놓는 기술. 이것이 바로 SKOS의 궁극기인 `"**어휘 매핑(Vocabulary Mapping)**"`입니다.

## 2. 해결책 제시: 5가지 글로벌 매핑 속성 (Mapping Properties)

초보 연구원들은 종종 "어? 12.3장에서 배운 `skos:related`나 `skos:broader`로 연결하면 되는 것 아닙니까?"라고 묻습니다. 

절대 안 됩니다. 앞서 배운 일반 관계 속성들은 **'같은 사전(동일한 ConceptScheme) 내부'**에서만 써야 하는 족보 규약입니다. 서로 다른 기관이 만든, 출신 성분이 완전히 다른 두 개념을 연결할 때는 반드시 아래의 특수한 `"**매핑 속성(Mapping Properties)**"`들을 꺼내 들어야 합니다.

1. **`skos:exactMatch` (정확히 일치):** 두 개념이 시맨틱적으로 100% 완벽하게 똑같을 때 사용합니다. (이 속성은 무시무시한 이행성(Transitivity)을 가집니다. A=B이고 B=C이면, 기계는 A=C라고 자동 추론합니다.)
2. **`skos:closeMatch` (거의 일치):** 두 개념이 매우 유사하지만, 뉘앙스나 범위가 미묘하게 달라서 100% 똑같다고 단정 지을 수 없을 때 사용하는 안전한 매핑입니다. (이행성이 없습니다.)
3. **`skos:broadMatch` (상위 매핑):** 외부 개념이 우리 개념보다 의미가 더 넓을 때 씁니다.
4. **`skos:narrowMatch` (하위 매핑):** 외부 개념이 우리 개념보다 의미가 더 좁을 때 씁니다.
5. **`skos:relatedMatch` (연관 매핑):** 외부 개념과 우리 개념이 횡적으로 연관되어 있을 때 씁니다.

## 3. 실전 적용: '서원(書院)'의 글로벌 크로스워크 (Turtle)

조선시대의 사설 교육 기관인 **'서원'**을 우리 연구실의 로컬 개념으로 만들고, 이를 세계 최대의 지식 창고인 위키데이터(Wikidata)와 미국 의회도서관(LCSH) 주제어에 연결하는 실전 코드를 작성해 보겠습니다.

```turtle
@prefix skos: [http://www.w3.org/2004/02/skos/core#](http://www.w3.org/2004/02/skos/core#) .
@prefix 국학: [http://aks.ac.kr/vocabulary/](http://aks.ac.kr/vocabulary/) .
@prefix wd: [http://www.wikidata.org/entity/](http://www.wikidata.org/entity/) .
@prefix lcsh: [http://id.loc.gov/authorities/subjects/](http://id.loc.gov/authorities/subjects/) .

# --- [로컬 개념의 선언] ---
국학:concept/서원 a skos:Concept ;
    skos:inScheme 국학:scheme/한국_전통건축 ;
    skos:prefLabel "서원"@ko ;
    skos:prefLabel "Seowon"@en ;
    
    # --- [글로벌 권위 데이터와의 매핑 (Crosswalk)] ---
    
    # 1. 위키데이터 매핑: 위키데이터에는 이미 '서원(Q484252)'이라는 정확한 항목이 존재합니다.
    # 이것은 시맨틱적으로 완벽히 동일하므로 exactMatch를 씁니다.
    skos:exactMatch wd:Q484252 ;
    
    # 2. 미국 의회도서관(LCSH) 매핑: LCSH에는 서원에 딱 맞는 단어가 없고, 
    # 서양식 '아카데미(Academies)'라는 주제어만 존재합니다.
    # 서원이 아카데미와 비슷하긴 하지만, 조선 성리학의 제사 기능 등을 고려하면 100% 같지는 않습니다.
    # 따라서 안전하게 closeMatch를 씁니다.
    skos:closeMatch lcsh:sh85000300 ;
    
    # 3. 상위 개념 매핑: 위키데이터의 범용적인 '학교(School, Q3914)' 개념을 
    # 우리의 상위 개념으로 연결해 둡니다.
    skos:broadMatch wd:Q3914 .
```

이 코드가 서버에 올라가는 순간, 기적이 일어납니다. 
전 세계의 인공지능과 검색 엔진들이 위키데이터나 LCSH를 긁어가면서 이 매핑 정보를 타고 우리 연구소 서버로 유입됩니다. 영미권 학자가 "Academies in Korea"를 검색할 때, 우리의 `국학:concept/서원`에 맵핑된 수만 건의 훌륭한 고문헌 데이터가 그들의 화면에 쏟아지게 되는 것입니다. 이것이 진정한 시맨틱 웹(Semantic Web)의 승리입니다.

## 4. 실무 트러블슈팅 (Street-smart Tips)

**시맨틱 아키텍트의 무관용 원칙: "exactMatch의 남용은 지식망을 파괴한다"**

디지털 인문학계, 특히 서구의 온톨로지를 동양 데이터에 이식하려는 연구원들이 가장 많이 저지르는 참사가 바로 `"**exactMatch의 남용**"`입니다. 번역의 강박증에 빠진 연구원들은 다음과 같은 코드를 짭니다.

* `국학:양반 skos:exactMatch wd:Q134150(서양의 귀족, Aristocracy)`
* `국학:성리학 skos:exactMatch wd:Q11973(유학, Confucianism)`

**경고합니다. 이것은 시맨틱 테러 행위입니다.** `exactMatch`는 논리학적으로 완전한 동치(A ≡ B)를 의미합니다. 양반을 서양의 중세 귀족(Aristocracy)에 `exactMatch`로 묶어버리는 순간, 추론 엔진은 서양 귀족의 속성(예: 영주권, 기사도)을 조선시대 양반에게 그대로 덮어씌우는 끔찍한 역사 왜곡을 저지르게 됩니다. 

문화적 특수성이 강한 인문학 데이터를 외부의 보편적인 어휘와 연결할 때는 **"무조건 `closeMatch`를 기본값(Default)으로 사용하라"**는 것이 시맨틱 아키텍트의 실무 황금률입니다. `closeMatch`는 "두 개가 비슷해서 같이 검색되면 좋겠지만, 논리적으로 완전히 똑같지는 않으니 추론을 강제로 전염시키지는 마라"라는 아주 훌륭하고 부드러운 타협안입니다. 

우리의 학문적 자존심(뉘앙스 차이)을 지키면서도, 글로벌 네트워크에 합류하는 가장 현명한 방법입니다.

## 5. 요약 및 [12장. 지식 조직체계(SKOS)] 마무리

* 서로 다른 기관이나 사전(Scheme)에 속한 개념들을 연결하여 글로벌 지식망을 형성할 때는 일반 관계 속성이 아닌, **`exactMatch`, `closeMatch`** 등의 특수한 매핑 속성을 사용해야 합니다.
* 이 매핑을 통해 우리 연구소의 로컬 시소러스는 위키데이터나 LCSH 같은 거대한 권위 데이터(Authority Data)와 연결되어, 데이터의 국제적 노출도와 상호운용성을 극대화할 수 있습니다.
* 문화적 특수성이 강한 동양 고문헌 개념을 서양의 범용 개념과 매핑할 때는, 치명적인 논리 오류를 막기 위해 `exactMatch`의 사용을 극도로 자제하고 **`closeMatch`**를 사용하는 것이 실무의 핵심입니다.
