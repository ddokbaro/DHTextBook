# 튜링 머신에서 폰 노이만 구조까지

컴퓨팅의 역사는 단순한 기술적 진보의 궤적이 아니라, '인간이란 무엇인가'를 묻는 철학적 질문의 연장선에 놓여 있습니다. 기술과 데이터가 진화의 패턴 속에 깊숙이 자리 잡으면서, 현대 인문학은 기계가 과연 인간성의 일부인지, 혹은 인간이 기계적 특성을 내재하고 있는지에 대한 근본적인 성찰을 요구받고 있습니다. 

이 장에서는 수학적 사유가 어떻게 물리적 기계로 구현되었으며, 이 과정에서 인간의 정체성과 노동의 사회적 맥락이 어떻게 재구성되었는지 심층적으로 살펴봅니다.

## 1. 철학적 및 역사적 배경: 전쟁과 기계적 알고리즘으로의 전환

20세기 중반, 제2차 세계대전이라는 극단적인 시대적 배경은 인간의 고유한 지적 영역으로 여겨졌던 '계산(Compute)' 행위를 기계의 영역으로 이전시키는 결정적 계기를 마련했습니다.

### 제2차 세계대전과 '인간 컴퓨터(Human Computer)'의 역사

1940년대 중반까지 '컴퓨터(Computer)'라는 단어는 전기를 먹고 작동하는 기계가 아니라 **사람의 직업을 지칭하는 명사**였습니다. 당시 컴퓨터란 연필과 종이, 그리고 수동식 기계 계산기를 이용해 복잡한 수학적 방정식을 풀어내는 '계산수'를 의미했습니다. 

미국 육군의 탄도 연구소(BRL)를 비롯한 군사 기관들은 전장에서 포탄이 날아가는 궤적을 예측하기 위해 막대한 양의 포격 제원표를 필요로 했습니다. 전쟁으로 인해 남성들이 대거 전선에 투입되면서, 이 방대하고 복잡한 계산 업무는 온전히 여성들의 몫으로 남겨졌습니다. 

:::{note} 역사가 지워버린 최초의 프로그래머, '애니악 식스(ENIAC Six)'
존 모클리와 J. 프레스퍼 에커트가 거대한 전자식 계산기인 애니악(ENIAC)의 개발을 제안했을 때, 이 기계에 생명을 불어넣은 것은 여성이었습니다. 수만 개의 진공관으로 이루어진 거대한 하드웨어에 복잡한 탄도학 방정식을 논리적으로 분해하여 입력하고 물리적인 배선을 연결한 최초의 프로그래머들은 캐슬린 맥널티, 진 바틱 등 6명의 여성이었습니다. 

그러나 1946년 2월 애니악이 언론에 공개되었을 때, 모든 조명은 기계를 발명한 남성 엔지니어들에게만 집중되었습니다. 디지털 인문학은 이 지점에서 컴퓨팅 역사의 이면에 감춰진 젠더적 편향성을 지적합니다. 계산이라는 행위가 가진 신체적 노고와 성별화된 노동의 맥락이 차가운 금속 하드웨어 뒤로 은폐되고, 지적 성취의 공로가 철저히 기계의 물리적 발명가들에게 독점된 사회적 재구성의 과정이었습니다.
:::

### 튜링 머신과 계산의 기계화

인간의 두뇌와 손끝에서 이루어지던 계산이 기계의 논리 회로로 넘어갈 수 있었던 사상적 토대는 영국의 수학자 앨런 튜링(Alan Turing)에 의해 확립되었습니다. 

튜링은 1936년 논문에서 **'튜링 머신(Turing Machine)'**이라는 가상의 기계 모델을 고안했습니다. 무한히 길게 분할된 테이프(Tape)와 기호를 읽고 쓰는 헤드(Head), 그리고 유한한 상태(State) 규칙표로 구성된 이 단순한 기계는, 명확한 알고리즘만 주어지면 인간의 복잡한 논리적 절차를 완벽하게 모방할 수 있음을 수학적으로 증명했습니다. 

이는 분산되어 있던 수많은 인간 컴퓨터들의 문제 해결 능력을 단 하나의 '보편적 기계 장치(Universal Turing Machine)'로 통합할 수 있다는 경이로운 철학적 선언이었습니다.

### 기계적 알고리즘으로의 전환이 갖는 철학적 의미

튜링 머신의 등장은 17세기 데카르트 이래 서구 철학을 지배해 온 '지능을 가진 인간' 대 '기계적 메커니즘'이라는 엄격한 이분법에 거대한 균열을 냈습니다. 지능은 물리적 신체와 철저히 분리되어, 기계라는 무기물 매체를 통해서도 구현될 수 있는 **'정보 처리 과정'**으로 재정의되었습니다.

| 개념 구분 | '인간 컴퓨터' 시대의 계산 (Turing 이전) | 기계적 알고리즘 시대의 계산 (Turing 이후) |
| :--- | :--- | :--- |
| **계산의 주체** | 고도로 훈련된 생물학적 인간 (주로 여성 수학자) | 무기물로 이루어진 논리 회로와 알고리즘 |
| **물리적 도구** | 연필, 종이, 책상, 수동식 기계 계산기 | 무한한 테이프, 기호를 읽고 쓰는 헤드, 상태표 |
| **한계와 특성** | 물리적 피로 수반, 인지적 판단 필요 | 결정론적, 규칙 기반의 끝없는 반복, 피로 없음 |
| **철학적 함의** | 신체와 결합된 인간 이성의 고유한 지적 활동 | 논리와 연산의 탈신체화, 보편적 지능의 기계적 이식 |

<br>

## 2. 폰 노이만 구조의 기술적 원리와 혁신성

앨런 튜링이 철학적 청사진을 제공했다면, 이를 현실의 공학적 모델로 완성하여 정보화 시대를 연 인물은 존 폰 노이만(John von Neumann)입니다.

### 물리적 배선의 한계와 에드박(EDVAC) 보고서

초기 컴퓨터인 애니악(ENIAC)은 프로그램을 변경할 때마다 기계의 논리 회로(플러그보드 전선)를 물리적으로 전부 새로 연결해야 하는 '하드와이어드(Hard-wired)' 방식을 사용했습니다. 

폰 노이만은 1945년 발표한 에드박(EDVAC) 보고서를 통해 **'프로그램 내장 방식(Stored-program)'**이라는 혁명적인 개념을 도입합니다. 명령어(Program)와 연산의 대상이 되는 숫자(Data)를 구별 없이 동일한 이진수 형태로 메모리에 저장함으로써, 물리적인 배선 변경 없이 소프트웨어만 교체하여 범용적인 작업을 수행할 수 있게 되었습니다.

### 폰 노이만 아키텍처의 구조

에드박 보고서가 제시한 컴퓨터의 구조는 특유의 급진적 최소주의 덕분에 오늘날까지도 모든 컴퓨터 설계의 정석으로 자리 잡고 있습니다.

:::{mermaid}
graph TD
    subgraph CPU [중앙처리장치 CPU]
        CU[제어 장치 Control Unit]
        ALU[산술논리 장치 ALU]
    end
    
    Memory[(메모리 Memory\n프로그램 & 데이터)]
    IO((입출력 장치 I/O))

    Memory <-->|데이터 버스| CPU
    Memory <-->|명령어 버스| CU
    CPU <--> IO
:::

:::{tip} 직관적 비유: 거대한 컴퓨터 주방의 논리학
복잡한 전자공학의 세계를 하나의 '고급 레스토랑 주방'에 비유해 볼 수 있습니다.

* **제어 장치 (총괄 셰프):** 메모리에서 명령어를 순서대로 인출하고 전체 기계의 작동과 요리 순서를 조율합니다.
* **산술논리 장치 (실무 부주방장):** 제어 장치의 지시에 따라 덧셈, 뺄셈 등 물리적인 논리 연산(칼질과 조리)을 수행합니다.
* **메모리 (수납장과 조리대):** 프로그램 코드(레시피)와 데이터(식재료)를 물리적 구분 없이 동일하게 저장합니다.
* **시스템 버스 (컨베이어 벨트):** 부품 간 데이터, 주소, 제어 신호를 실어 나르는 핵심 통로입니다.
* **입출력 장치 (배달원과 웨이터):** 외부 세계의 주문을 받고 완성된 결과를 내보냅니다.
:::

## 3. 폰 노이만 이후의 발전과 한계

### 마이크로프로세서와 무어의 법칙

1971년 인텔 4004 칩의 발명으로 거대한 CPU가 손톱만 한 실리콘 칩(마이크로프로세서) 하나에 집적되었습니다. 이는 **무어의 법칙(Moore's Law)**, 즉 마이크로칩에 집적할 수 있는 트랜지스터의 수가 약 2년마다 두 배씩 증가한다는 예측과 맞물려 개인용 컴퓨터(PC) 혁명을 이끌었습니다. 지식 네트워크의 팽창과 연산 능력의 민주화가 이루어진 것입니다.

### 인공지능 시대와 '폰 노이만 병목 현상'

그러나 딥러닝과 거대 언어 모델(LLM)의 시대가 도래하면서 폰 노이만 구조는 치명적인 한계에 직면했습니다. 

:::{warning} 폰 노이만 병목 현상 (Von Neumann Bottleneck)
요리사(CPU)의 처리 속도는 비약적으로 발전했지만, 수납장(메모리)에서 재료를 가져오는 좁은 통로(시스템 버스)의 속도가 이를 따라가지 못하는 현상입니다. 

수십억 개의 행렬 곱셈을 동시에 수행해야 하는 AI 연산에서, CPU는 데이터를 기다리느라 멍하니 서 있게 됩니다. 데이터를 버스를 통해 논리 회로로 끌어오는 과정은 실제 연산보다 **수십 배 더 많은 전력을 소모**하며, 이는 기후 위기 시대에 심각한 에너지 낭비를 초래합니다.
:::

### 병목을 극복하기 위한 하드웨어 혁신

이러한 한계를 타파하기 위해 최신 하드웨어 아키텍처는 극적인 혁신을 거듭하고 있습니다. 

| 프로세서 구분 | 구조적 특징 및 동작 원리 | 인공지능 시대의 역할 (주방 비유) |
| :--- | :--- | :--- |
| **CPU** | 소수의 강력한 코어, 직렬 명령어 순차 처리 | 뛰어난 총괄 셰프. 복잡한 코스 요리에 필수적이나 단순 병렬 작업에 비효율적. |
| **GPU** | 수천 개의 단순 코어로 동시다발적 병렬 처리 | 수천 명의 주방 보조. 단일 품목 대량 생산에 특화되어 거대 AI 모델 **학습(Training)** 주도. |
| **NPU** | 뇌의 시냅스 연결 방식을 모방한 특수 아키텍처 | 극도의 저전력으로 AI **추론(Inference)** 전담. 스마트폰 등 엣지 디바이스 탑재. |
| **PIM** <br>(Processing-in-Memory) | 메모리 물질 자체의 특성을 활용해 내부 연산 | 수납장 안에서 스스로 조리되는 요리. 데이터 이동 자체를 없애 폰 노이만 병목을 근본적으로 소거. |

## 4. 결론: 포스트 휴먼 시대의 기계와 인문학적 성찰

종이 위에서 연필로 방정식을 풀던 여성 수학자들의 손끝에서 출발하여, 튜링의 추상적인 기계를 거쳐, 폰 노이만의 천재적인 하드웨어 설계로 구현된 컴퓨팅의 역사는 인류의 지적 한계를 가장 역동적으로 확장해 왔습니다.

딥러닝이라는 거대한 데이터의 압력 아래 폰 노이만 아키텍처가 한계를 겪고, 이를 극복하기 위해 생물학적인 뇌를 모방한 NPU나 PIM 같은 **비 폰 노이만(Non-Von Neumann) 구조**가 대두되는 작금의 현상은 철학적으로 매우 상징적입니다. 기계가 점점 '생각하는 지능'에 다가갈수록, 그 효율성을 높이기 위해 역설적으로 수학적 논리가 아닌 유기적인 인간의 두뇌를 닮아가는 방향으로 회귀하고 있는 것입니다.

디지털 인문학이 컴퓨팅 아키텍처의 역사를 탐구해야 하는 이유는 명확합니다. 컴퓨터의 발전사는 단순한 도구의 진화록이 아니라, 기술이라는 거울을 통해 인간의 이성과 지능의 한계, 그리고 본성을 끊임없이 해체하고 새롭게 규명해 온 **철학적 인간학의 역사**이기 때문입니다.
