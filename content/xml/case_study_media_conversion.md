# 매체 전환의 흔적 보존: `<illustGroup>`을 통한 이미지 매핑과 `<emph>`를 활용한 시각적 속성 제어

디지털 인문학에서 아날로그 사료를 전사(Transcription)하여 XML로 변환하는 작업은 본질적으로 `"**매체 전환(Media Conversion)**"` 행위입니다. 이 과정에서 텍스트의 논리적 의미는 추출되지만, 종이 매체가 가지고 있던 고유한 물성(物性)인 레이아웃, 삽화, 글꼴의 강조 효과 등은 쉽게 휘발되어 버립니다.

특히 근현대 잡지는 단순한 줄글의 나열이 아니라, 당대의 시각 문화와 편집 디자인이 집약된 시각 매체입니다. 국사편찬위원회는 이러한 아날로그 매체의 시각적 흔적을 디지털 데이터베이스 내부에 영구히 결합하기 위해 매우 정교한 장치들을 마련했습니다. 이 장에서는 `history.dtd`와 `ma_045.xml` 샘플을 통해 이미지 매핑과 타이포그래피 제어의 원리를 해부합니다.

## 1. 원본 이미지와의 동기화: `<illustGroup>`과 `<illustration>`

사용자가 웹 포털에서 잡지 기사의 텍스트를 읽을 때, 학술적 고증을 위해서는 반드시 해당 텍스트가 실려 있는 `"**원본 스캔 이미지(원문)**"`를 함께 대조해 볼 수 있어야 합니다. 



XML 텍스트와 원본 스캔 이미지 파일들을 논리적으로 연결(Mapping)하기 위해 국편 DTD는 `<illustGroup>` (Illustration Group) 요소를 도입했습니다. `ma_045.xml` (학풍) 샘플 데이터의 개별 기사(`<level3>`) 헤더 영역을 살펴보겠습니다.

**[ma_045.xml의 이미지 매핑 사례]**
```xml
<level3 id="ma_045_0130_0090">
    <front>
        <biblioData>
            <title><mainTitle>兩班制度論</mainTitle></title>
            <creator><author><name>高在國</name></author></creator>
        </biblioData>
        <illustGroup>
            <illustration begin="ma_045_0130_0064" end="ma_045_0130_0071"/>
        </illustGroup>
    </front>
    <text>
        <content>...</content>
    </text>
</level3>
```

### 1.1 `begin`과 `end` 속성의 정보공학적 의도
여기서 `@begin`과 `@end` 속성값으로 부여된 `ma_045_0130_0064` 등의 식별자는 다름 아닌 서버에 저장된 **실제 이미지 파일의 이름(또는 ID)**입니다. 
"양반제도론"이라는 이 기사는 종이 잡지 원본에서 `0064`번 이미지부터 `0071`번 이미지까지 총 8페이지에 걸쳐 인쇄되어 있다는 물리적 사실을 기계에게 알려주는 것입니다. 

이러한 메타데이터 덕분에, 웹 개발자들은 사용자가 "양반제도론" 기사를 클릭하는 순간 원본 이미지 뷰어에 정확히 해당 8장의 스캔 이미지를 슬라이드로 띄워주는 자동화된 뷰어(Viewer) 인터페이스를 구현할 수 있습니다.

## 2. 타이포그래피의 디지털 화석화: `<emph>` 요소 ★

종이 잡지의 본문에는 필자가 특정 단어를 강조하기 위해 굵은 글씨(Bold)를 쓰거나, 밑줄(Underline)을 긋거나, 붉은색 먹을 칠한 타이포그래피적 요소들이 혼재되어 있습니다. 

일반적인 웹 개발자라면 이를 단순히 HTML의 `<b>`나 `<u>` 태그로 처리하려 하겠지만, 디지털 문헌학에서 텍스트는 시각적 표현 이전에 **의미론적 데이터**여야 합니다. 국사편찬위원회의 `history.dtd`는 이를 통제하기 위해 `"**<emph>**"` (Emphasis)라는 추상화된 요소를 선언했습니다.

**[history.dtd의 emph 요소 선언부]**
```dtd
<!ELEMENT emph (#PCDATA | %p.zz.cont;)*>
<!ATTLIST emph
    type (bold | color | underline | underline1 | underline2 | line | italic) "bold"
    space (one | two | three | four) "one"
    align %h.align; 
>
```

### 2.1 시각적 속성의 구조적 통제 (`@type`)
DTD 명세서에서 볼 수 있듯이, `<emph>` 태그 자체는 그저 "이 부분이 강조되었다"는 추상적인 의미만을 가집니다. 구체적으로 원본에서 어떻게 시각적으로 강조되었는지는 `"**@type**"` 속성의 제한된 목록(`bold`, `color`, `underline`, `italic` 등) 중에서만 선택하도록 강제했습니다.

**[적용 예시]**
```xml
<paragraph>
    이러한 현상은 우리의 <emph type="underline">근대화 과정</emph>에서 
    가장 <emph type="bold">치명적인 오류</emph>로 작용하였다.
</paragraph>
```
이러한 설계는 두 가지 거대한 장점을 가집니다.
1. **표준의 준수:** HTML과 같은 표현용 언어(Presentation Language)와 XML 같은 구조적 언어(Structural Language)를 철저히 분리한다는 XML의 대원칙을 지킵니다.
2. **다중 매체 렌더링(Multi-channel Rendering):** 훗날 이 데이터를 웹(HTML)으로 출력할 때는 XSLT를 이용해 `<emph type="bold">`를 `<strong>`으로 변환하고, 점자책이나 음성 읽기 기기(TTS)로 출력할 때는 해당 단어를 더 큰 목소리로 읽도록 변환할 수 있는 무한한 매체 확장성을 확보합니다.

## 3. 결론: 가장 진보적인 아카이빙 철학

지금까지 해부한 한국근현대잡지자료의 XML 스키마는 단순한 데이터 입력 포맷이 아닙니다. 

* `<level>`을 통한 논리적 분할과 상속
* `<index>`를 통한 색인 데이터베이스 연동
* `<illustGroup>`과 `<emph>`를 통한 종이 매체의 물리적 흔적 보존

이는 과거의 죽은 종이 문헌을 현대의 관계형 데이터베이스(RDB) 및 시맨틱 웹 생태계에 편입시키면서도, 아날로그 사료가 가졌던 본래의 모습(Context)을 단 하나도 놓치지 않으려는 국사편찬위원회의 치열한 학술적 고뇌와 정보공학적 성취의 결정체입니다.

잡지 자료의 뼈대와 혈관을 완벽히 파악했으니, 다음 장에서는 동아시아 편년체 사료의 정점이자 세계기록유산인 **"조선왕조실록 공공데이터 XML 구조"**를 해부하며, 국가 최고 권력의 기록이 어떻게 디지털 구조물로 재탄생했는지 탐구하겠습니다.
