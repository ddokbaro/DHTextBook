# 경량 도구(Datasette)를 활용한 코딩 없는 REST API 배포 실무

이전 장에서 우리는 데이터베이스를 사일로(Silo)에서 구출하여 전 세계와 연결하는 `"**데이터의 서비스화(DaaS)**"`와 `"**REST API**"`의 철학적 당위성을 배웠습니다. 

하지만 철학에 동의한다고 해서 당장 파이썬(Python)의 Django나 자바(Java)의 Spring 프레임워크를 수개월간 공부하여 백엔드 서버를 직접 구축할 수는 없는 노릇입니다. 인문학 연구자는 시스템 개발자가 아니라, 데이터를 해석하고 지식을 생산하는 사람이기 때문입니다. 

이러한 딜레마를 완벽하게 타파하기 위해 디지털 인문학과 데이터 저널리즘 생태계에서 구세주처럼 등장한 오픈소스 도구가 있습니다. 바로 `"**Datasette(데이터셋)**"`입니다. 이 장에서는 여러분이 정성껏 구축한 로컬 `.db` 파일 하나를 코딩 한 줄 없이 완벽한 웹 서비스이자 API로 탈바꿈시키는 경이로운 실무를 체험합니다.

## 1. Datasette: 데이터 저널리즘이 낳은 마법의 도구



**Datasette**는 Django 프레임워크의 공동 창시자인 사이먼 윌리슨(Simon Willison)이 데이터 저널리스트들과 인문학 연구자들을 위해 개발한 오픈소스 도구입니다. 

이 도구의 철학은 매우 극단적이고 매력적입니다. 
`"**잘 만들어진 SQLite 데이터베이스 파일 하나만 던져주면, 그 즉시 데이터를 탐색할 수 있는 아름다운 웹사이트와 기계가 읽을 수 있는 완벽한 JSON API를 1초 만에 자동 생성해 주겠다.**"`

복잡한 라우팅(Routing) 설계도, 데이터베이스 연동 코드 작성도 필요 없습니다. 데이터 자체가 곧 API 서비스가 되는 기적을 보여줍니다.

## 2. 실습: 로컬 환경에서 1초 만에 API 서버 띄우기

앞선 파트의 실습을 통해 우리는 DBeaver나 파이썬을 이용해 조선시대 인물 정보가 담긴 `joseon_archive.db`라는 SQLite 파일을 완성해 두었습니다. 이제 이 파일을 서비스로 띄워보겠습니다.

### 2.1 Datasette 설치 및 실행
파이썬이 설치된 환경(터미널 또는 명령 프롬프트)에서 아래의 명령어를 입력합니다.

```bash
# 1. Datasette 설치 (최초 1회만)
pip install datasette

# 2. 내가 만든 데이터베이스 파일을 지정하여 서버 실행
datasette serve joseon_archive.db
```

이 명령어를 치는 순간, 콘솔창에 `http://127.0.0.1:8001` 이라는 주소가 나타납니다. 웹 브라우저를 열고 이 주소로 들어가 보십시오.

### 2.2 자동 생성된 웹 UI와 SQL 샌드박스
놀랍게도 여러분의 데이터베이스 안에 있는 `person_tb`, `office_tb` 등의 테이블 목록이 깔끔한 웹 인터페이스로 변환되어 나타납니다. 테이블 이름을 클릭하면 엑셀처럼 데이터를 열람할 수 있고, 페이징(Pagination) 처리도 이미 완벽하게 되어 있습니다.
심지어 방문자가 직접 SQL 쿼리를 쳐볼 수 있는 `"**SQL 샌드박스(Sandbox)**"`까지 무료로 제공됩니다.

### 2.3 URL에 '.json'만 붙이면 완성되는 기적의 API ★
가장 소름 돋는 기능은 API로의 전환입니다. 여러분이 웹 브라우저에서 '이순신'을 검색한 뒤, 주소창의 끝부분에 `"**.json**"` 이라는 네 글자만 덧붙여 보십시오.

* **웹페이지 모드:** `http://127.0.0.1:8001/joseon_archive/person_tb?person_name=이순신`
* **API 모드:** `http://127.0.0.1:8001/joseon_archive/person_tb.json?person_name=이순신`

엔터를 치는 순간, 화려한 웹 UI는 사라지고 기계가 가장 사랑하는 완벽한 형태의 `"**JSON 데이터**"`가 화면에 출력됩니다. 여러분은 백엔드 코드를 단 한 줄도 짜지 않고 REST API 서버 구축에 성공한 것입니다.

## 3. 세상을 향한 출항: 클라우드 무료 배포(Publishing)

로컬(`127.0.0.1`)에서 실행된 서버는 내 컴퓨터를 끄면 사라집니다. 이를 전 세계 누구나 24시간 접속할 수 있도록 구글 클라우드(Google Cloud Run)나 버셀(Vercel), 허로쿠(Heroku) 같은 퍼블릭 클라우드에 올리는 작업을 `"**배포(Deployment)**"`라고 합니다.

일반적인 배포 작업은 도커(Docker) 컨테이너를 세팅하고 CI/CD 파이프라인을 구축하는 등 엄청난 엔지니어링 지식을 요구합니다. 하지만 Datasette는 이마저도 명령어 하나로 자동화해 버렸습니다.



### 3.1 Vercel을 이용한 무료 배포 실습
서버리스(Serverless) 호스팅의 강자인 Vercel에 우리의 역사 아카이브를 배포해 보겠습니다.

```bash
# 1. Datasette용 Vercel 퍼블리시 플러그인 설치
pip install datasette-publish-vercel

# 2. 데이터베이스를 통째로 Vercel 클라우드로 쏘아 올리기
datasette publish vercel joseon_archive.db --project my-dh-archive
```

단 1~2분의 업로드 및 빌드 시간이 지나면, 터미널 창에 `https://my-dh-archive.vercel.app` 과 같은 근사한 글로벌 URL이 발급됩니다. 
이제 여러분은 이 URL을 전 세계의 동료 학자들에게 이메일로 보낼 수 있으며, 논문의 부록으로 당당하게 기재할 수 있습니다. 

## 4. 에필로그: 데이터, 지식의 우물이 되다

축하합니다! 여러분은 엑셀이라는 낡은 창고에 방치되어 있던 플랫 데이터를 끄집어내어,
1. 제1~제3 정규화 원칙에 따라 `"**논리적으로 해체하고 조립(Part 3)**"`했습니다.
2. UTF-8과 BOM의 늪을 건너 RDB라는 견고한 성채에 `"**안전하게 적재(Part 4)**"`했습니다.
3. SQL 질의어를 통해 다중 테이블을 JOIN하며 숨겨진 역사적 `"**관계망을 복원(Part 5)**"`해 냈습니다.
4. 그리고 마침내, 이 거대한 지식베이스를 Datasette를 통해 전 세계 학자들이 길어 마실 수 있는 `"**살아있는 지식의 우물(API)**"`로 세상에 개방했습니다.

디지털 인문학(Digital Humanities)은 단순히 인문학에 컴퓨터 기술을 덧칠하는 것이 아닙니다. 인류의 오래된 유산을 기계가 이해할 수 있는 보편적인 데이터의 언어로 번역하고, 그것을 시공간의 제약 없이 무한히 확장 가능하도록 엮어내는 위대한 지적 여정입니다. 

여러분이 구축한 이 작은 데이터베이스가 훗날 또 다른 누군가의 연구와 결합하여 거대한 지식의 별자리를 이룰 때, 우리는 비로소 진정한 의미의 디지털 인문학에 다다르게 될 것입니다. 긴 여정을 함께해 주셔서 감사합니다.
